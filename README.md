# Scholarship Tracker AI

An AI-powered platform to help students track:

- Scholarship deadlines
- Daily study goals
- MSc application progress
- Skill development milestones
- Internship applications

## Features (Planned)

- Dashboard
- Daily Task Tracker
- Scholarship Database
- Progress Analytics
- AI Study Recommendations

## Goal

Build a complete scholarship and career tracking system for students preparing for higher education abroad.
